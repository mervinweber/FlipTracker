# v0.6 Selling Readiness Release

Goal: make a fresh week of eBay listing faster by catching incomplete drafts before eBay rejects them and by turning corrections into a focused queue.

## Task 1 - Listing Readiness

- Validate title, price, category, seller defaults, images, package measurements, and known required item specifics.
- Use one readiness result for row status, editor guidance, staging, and publishing.
- Block staging when required local information is missing.

## Task 2 - eBay Category Aspects

- Fetch required and recommended aspects from the eBay Taxonomy API.
- Normalize allowed values, selection mode, cardinality, and length limits.
- Begin with clothing leaf categories, then reuse the same capability for every category.

## Task 3 - Exception Queue

- Filter drafts by missing category, photo, price, shipping, or specifics.
- Show all blocking reasons without opening every record.
- Support Save and Next so a stack can be corrected continuously.

## Task 4 - Shipping Guardrails

- Compare the chosen fulfillment policy with the selected package profile.
- Prevent known ineligible combinations such as games with Media Mail.
- Warn when eBay Standard Envelope or package measurements exceed known limits.
- Require measured values for custom merchandise before publishing.

## Task 5 - Keyboard Workflow

- Add Save, Save and Next, previous/next step, and close shortcuts.
- Avoid shortcuts while a multiline field or category search is active.
- Keep every shortcut available through visible controls.

## Task 6 - Reliability

- Add tests for readiness rules, listing lifecycle transitions, and import deduplication.
- Add friendly action/mutation errors and retry guidance.
- Keep staging and publishing idempotent.

## Task 7 - Performance And Smoke Testing

- Split scanner and listing-heavy UI code from the initial bundle.
- Test desktop intake, mobile photos, pricing, category correction, staging, publishing, and sold sync.
- Verify one book, DVD, game, card, clothing item, and general-merchandise exception.

## Release Gate

- Production build passes.
- No known blocker can reach eBay staging without a local explanation.
- The exception queue can correct a mixed stack without returning to the main table.
- Production Convex functions and the Vercel deployment pass smoke testing.

Authentication and owner-scoped data remain a separate beta-access release. v0.6 can serve the current single-owner workflow, but it must not be opened to unrelated testers until authentication is complete.
