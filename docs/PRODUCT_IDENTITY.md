# Product Identity

FlipTracker should feel like a polished collector/reseller command center: practical, fast, trustworthy, and a little premium.

## Brand Position

FlipTracker helps collectors and resellers turn messy inventory into clear decisions. It should feel less like a generic database and more like a focused tool for finding margin, prioritizing listings, and understanding a collection.

## Personality

- Clear
- Confident
- Collector-aware
- Operational
- Polished without feeling flashy
- Practical before decorative

## Logo Direction

Open direction to settle before public release:

- A compact mark that combines resale motion with inventory tracking.
- Possible motifs: price tag, stack/card, cartridge/disc, checkmark, upward flip/arrow.
- Should work as a small PWA icon and as a wordmark.
- Avoid overly playful game-controller logos; the app is broader than video games.

## Color Palette Direction

Current UI is dark with blue/teal primary actions and amber value-review states. Long term, keep the product in a focused, work-friendly palette:

- Background: deep neutral, not pure black.
- Surface: layered dark slate/charcoal.
- Primary: confident blue for core actions.
- Secondary accent: teal for value/opportunity and product identity.
- Value/research accent: amber/gold for attention and value-check states.
- Success: green for profitable/list-ready states.
- Risk/destructive: restrained red.

Avoid a one-note palette. The app should not become all blue, all purple, or all beige.

## Typography Direction

- Use a clean, modern sans-serif optimized for dense interfaces.
- Prioritize readability in tables, filters, modals, and dashboards.
- Avoid oversized marketing-style type inside operational screens.
- Keep numeric values easy to scan.

Potential future font choices:

- Inter
- Geist
- IBM Plex Sans
- System UI until a final brand pass

## UI Design Language

- Dense but calm.
- Tables should be scannable and sortable/filterable.
- Modals should be structured into clear sections.
- Use status pills, badges, and subtle row states for workflow signals.
- Keep actions obvious but not noisy.
- Prefer direct workflow controls over explanatory text.
- Cards are for metrics and repeated records, not every page section.
- Inventory workflows should support repeated use, not one-time onboarding.

## Product Voice

The app should use plain operational language:

- "Needs value check"
- "List first"
- "Worth listing"
- "Bundle"
- "Hold"
- "Research"
- "Export"

Avoid cute labels where precision matters.

## Future Design Work

- Finalize logo and app icon from the current tag/stack mark direction.
- Promote CSS color tokens into a reusable design system.
- Choose final font stack.
- Create reusable button, badge, field, modal, and table styles.
- Define inventory status and strategy badge colors.
- Create empty states and loading states that feel product-ready.
