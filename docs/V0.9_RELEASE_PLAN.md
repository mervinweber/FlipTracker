# v0.9 Private Beta Release

FlipTracker v0.9 moves the current single-seller application to authenticated, owner-scoped private beta without interrupting the existing production workflow.

## Delivered In This Slice

- Optional Clerk sign-in gate for React/Vite and Convex.
- Owner IDs and owner indexes across inventory, photos, intake, research, listings, sales, cross-listing records, and eBay seller records.
- One-time, admin-key-protected assignment of legacy data to the first authenticated owner.
- Owner-specific eBay OAuth connections and seller defaults, including owner-aware active-listing and sold-order imports.
- Native eBay-app/Seller Hub listing revisions through a read-merge-revise Trading API workflow.
- Listing lifecycle activity records and an eBay operations inbox for sync errors, stale staged offers, and incomplete links.
- Regression tests for native eBay item-specific preservation and XML/condition mapping.

## Activation Order

Do these steps in order. Keep `FLIPTRACKER_AUTH_REQUIRED` unset until the existing records have been assigned.

1. Create a Clerk application and enable the sign-in methods intended for beta.
2. In Clerk, create the Convex JWT template/integration and copy its issuer domain.
3. Set `CLERK_JWT_ISSUER_DOMAIN` in both Convex development and production.
4. Copy `docs/snippets/convex-auth.config.ts.txt` to `convex/auth.config.ts`.
5. Set `VITE_CLERK_PUBLISHABLE_KEY` locally and in Vercel Production/Preview.
6. Run `npx convex dev --once`, then `npm run build`.
7. Sign in with the account that will own the existing FlipTracker data.
8. Use the in-app **Assign Existing Data** action and enter the current private seller access key.
9. Confirm inventory, photos, listings, sales, and eBay Seller Connection all load for that account.
10. In a separate browser session, confirm an unauthenticated visitor cannot enter the app and a second test account cannot see the owner's records.
11. Set `FLIPTRACKER_AUTH_REQUIRED=true` in Convex development and production.
12. Deploy Convex and Vercel, then repeat the production smoke matrix.

## Clerk Configuration

Local `.env.local` and Vercel:

```text
VITE_CLERK_PUBLISHABLE_KEY=pk_test_or_live_value
```

Convex development and production:

```bash
npx convex env set CLERK_JWT_ISSUER_DOMAIN "https://YOUR-CLERK-ISSUER"
npx convex env set --prod CLERK_JWT_ISSUER_DOMAIN "https://YOUR-CLERK-ISSUER"
```

After the first-owner claim and isolation checks:

```bash
npx convex env set FLIPTRACKER_AUTH_REQUIRED true
npx convex env set --prod FLIPTRACKER_AUTH_REQUIRED true
```

The Clerk publishable key is browser-safe. Clerk secret keys, eBay tokens, Convex deploy keys, Gemini keys, and the FlipTracker admin key must never use a `VITE_` prefix.

## Release Gate

- Convex codegen/typecheck, `npm test`, and `npm run build` pass.
- Existing records have an owner and remain visible to the first owner.
- A second account sees no first-owner records.
- Each account has a separate eBay OAuth connection/settings record.
- Desktop and phone can sign in, see the same records, and manage the same photo queue.
- Book, movie, game, card, clothing, and general-merchandise readiness checks pass.
- Native eBay-app listings and FlipTracker Inventory API listings can be identified and updated through the correct API path.
- Sold sync cannot create a duplicate sale and imported unmatched sales belong to the signed-in owner.
- A fresh Excel export and listings CSV export have been retained as a rollback backup.

## Deferred Beyond The First v0.9 Beta

- Saved per-owner intake and shipping presets.
- Automated backup scheduling and restore UI.
- Public signup, subscriptions, and team accounts.
